# Sitio de Diego Ochoa

Versión de contenido inmobiliario creada a partir de la estructura visual del sitio del Dr. Aarón Acosta. Se mantuvieron la disposición, los estilos y las interacciones; se sustituyeron los textos, las imágenes, los datos de contacto, los servicios y las preguntas frecuentes.

## Desarrollo local

Requiere Node.js 22.19 o superior.

```sh
npm ci
npm run dev
```

Comprobaciones:

```sh
npm run check
npm run build
```

## Datos por confirmar

Consulta [CONTENT-NOTES.md](CONTENT-NOTES.md) antes de publicar. El dominio de ejemplo mantiene el sitio fuera de los buscadores hasta que se configure `PUBLIC_SITE_URL` con el dominio definitivo.
